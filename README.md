# Machine Learning Based Energy Management System for Smart Buildings

## Project Overview
A web-based energy management system developed using Python and Django to monitor energy usage, detect anomalies, predict energy consumption, and help improve energy efficiency in smart buildings.

## Technologies Used
- Python
- Django
- Machine Learning
- Pandas
- Scikit-learn
- HTML
- CSS
- JavaScript

## Features
- User authentication
- Energy consumption monitoring
- Anomaly detection
- Energy usage prediction
- Energy theft/anomaly alerts
- Device scheduling
- Data visualization

## How to Run

1. Clone the repository.
2. Install the required packages.
3. Run the Django server.

```bash
pip install -r requirements.txt
python manage.py runserver
```

## Project Purpose
This project aims to improve energy efficiency in smart buildings using machine learning techniques and web-based monitoring.
